## ✨ Seções

- **Home** — Apresentação, download do currículo e acesso aos projetos
- **Sobre Mim** — Resumo profissional e diferenciais
- **Habilidades** — Tecnologias organizadas por área (desenvolvimento, dados e infraestrutura)
- **Experiência** — Linha do tempo com a trajetória profissional
- **Projetos** — Lista dinâmica dos repositórios do GitHub (via API)
- **Contato** — LinkedIn, GitHub, Instagram, WhatsApp e e-mail

## 🛠️ Tecnologias

- **Next.js 12** — Framework React com renderização estática
- **React 17** + **Styled Components**
- **React Icons** — Ícones
- **GitHub REST API** — Listagem dos projetos em tempo real

## 🚀 Como executar localmente

```bash
# instale as dependências
npm install

# rode em modo desenvolvimento
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## 📦 Build de produção

```bash
npm run build
npm run export
```

O site é publicado automaticamente no **GitHub Pages** via GitHub Actions a cada `push` na branch `master`.
